# ATHLETEIQ frontend

This Next.js app serves the ATHLETEIQ demo UI. For setup and the backend startup command, follow the repository [README](../README.md).

Start the frontend from this folder with:

```powershell
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000). Use **Try your data** in the sidebar to edit the 14-day football input sequence and run the trained model.
